# Coffee Shop Sales Dashboard

Dashboard interaktif yang dibuat menggunakan **Power BI** untuk menganalisis penjualan Coffee Shop.  
Visualisasi ini membantu melihat total revenue, tren penjualan bulanan, produk terlaris, serta perbandingan penjualan antar lokasi toko.

## 📌 Insight Utama
- Revenue total: **26M** dengan **149K transaksi**  
- Lokasi dengan revenue tertinggi: **Hell's Kitchen**  
- Produk kategori **Coffee** menyumbang revenue terbesar  
- Produk **Barista Espresso** dan **Hot Chocolate** paling banyak menghasilkan revenue
